# Parallel Session Coordination

## File ownership
| File | Owner | Status |
|------|-------|--------|
| src/rate_limiter.py | Session A | in progress |
| src/rate_limiter_config.py | Session A | not started |
| src/app.py | Session B | waiting on Session A contract commit |
| tests/test_rate_limiter.py | Session B | not started |

## Handoff protocol
Session A must commit src/rate_limiter.py before Session B reads it.
Session B must not modify src/rate_limiter.py.

## Interface contract (committed before either session begins)
Session A will implement:
  RateLimiter.check(client_id: str) -> bool   # True = request allowed
  RateLimiter.record(client_id: str) -> None  # log the request
Session B will call this exact interface — no changes to it.
